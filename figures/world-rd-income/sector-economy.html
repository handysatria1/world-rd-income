Plotted values and sources

Employment counts persons, not full-time equivalents. Productivity is current basic-price GVA per employed person, using exact economy/year/sector joins and market exchange rates; it is not PPP-adjusted or output per hour. Sector-panel medians are unweighted across available selected economies. Basque Country is a region within Spain.

Data, methods and ready-made figures

Employment and GVA use the same six groups covering A–T. Goods exports use manufacturing divisions 20, 21, 26–30 and 10–19, 22–25, 31–32, plus an explicit other/unallocated residual. Division 33 repair/installation services is outside OECD BTiGE's goods-product scope. Eustat's native technology groups are adjusted to the supplied division classification. Missing cells are not replaced with zero.
